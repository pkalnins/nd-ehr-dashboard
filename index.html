Open Items

  • Patient data truncation (ChARM): The ChARM API appears to export only patients registered during the clinic's initial onboarding period. Clinic 2, for example, exported 1,120 patient records despite ~8,829 unique patients being referenced in encounter data. This issue has been raised with ChARM support and is under investigation.
  • Server errors during export (ChARM): Some resources — particularly CarePlan and MedicationRequest — encountered intermittent server errors during download, resulting in incomplete record counts for those resources. This appears to be a ChARM infrastructure issue rather than a data problem, and has been noted for both clinics.
  • Expanded API access (ChARM): DocumentReference and Medication have both been downloaded for Clinic 2. Discharge summaries contain rich provider-written lifestyle recommendations (see section above). Medication records (142 unique drugs, RxNorm-coded) were fetched individually by ID — ChARM does not support the standard bulk Medication list endpoint. Clinic 1 still needs re-authorization to download these two resources. Clinics 3–7 will receive expanded access automatically.
  • Clinic onboarding (Clinics 3–7): Awaiting refresh tokens from clinic administrators to begin data download for the remaining 5 clinics.
